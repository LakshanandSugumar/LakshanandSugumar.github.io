# Sensor & HMI Subsystem — Power Budget

**Lakshanand Sugumar — Team 302 — EGR314 Spring 2026**

---

## Overview

This page presents the complete power budget for the Sensor & HMI subsystem of the R6 Recon Amphibot. The analysis verifies that all active components on the 3.3 V rail are accounted for, total peak current is calculated under worst-case conditions, a safety margin is applied, and the selected regulator can safely supply the required load.

The subsystem operates from a single regulated **3.3 V rail** generated by the **AP63203WU-7 synchronous buck regulator** (3 A rated). In the final V1 system, 3.3 V is supplied to this board via the upstream ribbon cable connector. The AP63203WU-7 on this board provides local regulation when the board is powered independently during development and testing.

## C. Safety Margin

A 20% safety margin is applied to account for startup surges, transient spikes, component tolerance, and temperature variation.

```
164.4 mA × 1.20 = 197.3 mA
```

**Total required current on 3.3 V rail: ≈ 200 mA**

## D. Regulator Validation

| Parameter                      | Value                  |
| ------------------------------ | ---------------------- |
| Regulator                      | AP63203WU-7            |
| Input voltage range            | 3.8–32 V               |
| Rated output current           | 3,000 mA               |
| Required current (with margin) | 200 mA                 |
| Headroom                       | 2,800 mA               |
| Utilization                    | 6.7% of rated capacity |

The AP63203WU-7 operates at well under 10% of its rated current capacity under normal conditions. This ensures stable output voltage, minimal self-heating, and ample headroom for transient loads.

## E. Power Source

In the final integrated system, 3.3 V is delivered to this board from the upstream ribbon cable. For standalone development and bench testing, the AP63203WU-7 was powered from a 9 V bench supply or wall adapter.

### Standalone Test Configuration

| Parameter                 | Value                    |
| ------------------------- | ------------------------ |
| Input source              | 9 V DC supply            |
| Buck converter efficiency | ≈ 90%                    |
| Output power              | 3.3 V × 0.200 A = 0.66 W |
| Input power               | 0.66 W / 0.90 = 0.73 W   |
| Input current at 9 V      | 0.73 W / 9 V ≈ 81 mA     |

A 9 V / 2.5 A adapter provides more than 30× the required input current, confirming no source-side constraint.

## G. Power Budget Summary

| Item                            | Value    |
| ------------------------------- | -------- |
| Total peak current (no margin)  | 164.4 mA |
| Total peak current (20% margin) | ≈ 200 mA |
| Regulator rated current         | 3,000 mA |
| Regulator headroom              | 2,800 mA |
| Regulator utilization           | 6.7%     |

The subsystem is well within the regulator's capacity. The BNO055 is the second-largest consumer at 12.3 mA in full fusion mode. The OLED remains the dominant load at 100 mA during active display output.
